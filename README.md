# Unity Normal Map Sphere

A Unity activity that shows how a **normal map** changes the way light interacts with a surface. A red sphere carries a custom normal map with my name on it (created in GIMP) and is lit by a colored point light.

## What this project includes

- A 3D **sphere** placed in the scene.
- A **material** with a custom **normal map** generated in GIMP from my name.
- A colored **point light** next to the sphere, so the relief of the normal map is visible.
- The sphere's base color set to **red**.

## Requirements

- Unity 2022.3 LTS or newer (replace with the version you used)
- Git
- GIMP (only if you want to recreate the normal map)
